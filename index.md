# Welcome to "Communicate using Markdown" 👋

## What is Markdown?

Markdown is a lightweight syntax for formatting text on GitHub.

### Where can you use Markdown?

- Comments on issues, pull requests, and discussions
- Files with the `.md` or `.markdown` extension
- Text snippets in Gists

#### What is a header?

A header is a larger piece of text used to start a section. There are six levels.
